## 🧩 DeepSeek Harness 插件

> 让 Agent 在自己的桌面上真正干活

- **[vision-use](https://github.com/zzy6-a/vision-use)** ![v0.3.0](https://img.shields.io/github/v/release/zzy6-a/vision-use?style=flat-square&label=&color=2e7d32)
  <sub>DSH Computer Use</sub>

  让 Agent 看见并操作 Windows 桌面 —— 会按控件名找按钮，点的时候鼠标不动；截被遮挡的窗口照样清楚；中文也能输入。

- **[dsh-prompt-enhance](https://github.com/zzy6-a/dsh-prompt-enhance)** ![v](https://img.shields.io/github/v/release/zzy6-a/dsh-prompt-enhance?style=flat-square&label=&color=2e7d32)
  <sub>提示词增强</sub>

  输入框旁的一键改写：把你随口一句要求，变成目标明确的任务书，不满意可以撤销。
