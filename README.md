### vision-use · DSH Computer Use

> 让 Agent 真正看见 Windows 屏幕并直接操作桌面：视觉通道（截屏进上下文）+ 鼠标/键盘控制 + Codex 风格蓝色覆盖层，按 **Esc** 随时中止。支持 Windows 原生 / WSL 环境自动识别。
