## Featured · 口袋记账 PocketBooks

> 复制、截图、说一句话，几秒钟记下一笔账。

支持手动记账与智能解析、剪切板识别、截图 OCR、语音「读一笔」、连续记多笔、快速模板、月度预算、自定义导出 Excel、数据备份与恢复。

- 数据完全本地：无需登录、无需联网，账单只存在你的手机里
- Kotlin · Jetpack Compose · Material 3 · Room · MVVM
